# 实验循环

每一轮实验只回答一个问题。

## 标准实验卡

```text
Hypothesis:
为什么这次修改可能改善结果？

Change:
只改什么？

Guard:
哪些硬约束必须保持 0 violation？

Metric:
用什么指标判断成功？

Budget:
最多运行几次 / 多久？

Stop:
什么情况下停止？

Result:
结果如何？

Decision:
接受 / 回滚 / 保留备选？
```

## 禁止的实验方式

- “继续优化一下”；
- “多试几个算法看看”；
- 同时改目标函数、参数、预处理、指标；
- 没有 baseline；
- 失败后继续在失败代码上叠补丁。

## 推荐

一次只改一个机制。  
实验失败就回滚，而不是把失败版本继续当母版。
