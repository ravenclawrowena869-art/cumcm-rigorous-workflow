# 推荐仓库目录

```text
competition/
├─ problem/                 # 官方题目与规则，只读
├─ data/
│  ├─ raw/                  # 原始附件，只读
│  └─ processed/
├─ src/
│  ├─ q1/
│  ├─ q2/
│  ├─ q3/
│  └─ q4/
├─ tests/
├─ runs/                    # 实验结果，不作为论文唯一来源
├─ frozen/
│  ├─ q1/
│  ├─ q2/
│  ├─ q3/
│  └─ q4/
├─ figures/
│  ├─ data/
│  ├─ scripts/
│  └─ final/
├─ paper/
│  ├─ source/
│  ├─ tables/
│  └─ final/
├─ docs/
│  ├─ decisions/
│  ├─ handoff/
│  ├─ validation/
│  └─ ai_log/
├─ prompts/
└─ submission/
```

## 原则

- `raw/` 永不修改。
- `runs/` 可以乱，`frozen/` 不能乱。
- 正式图只能读取 `frozen/` 或明确冻结的 paper metrics。
- 论文表格最好由脚本或固定 CSV 生成。
- AI 临时输出不能直接覆盖 frozen。
