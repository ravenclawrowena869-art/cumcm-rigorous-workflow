# v2.1 Shared Three-GPT Runtime Skill Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 `cumcm-rigorous-workflow` 实施为 FYQ、XXT、CYQ 三套 GPT 共用的轻量 Runtime Skill，并把华数杯三等奖评委反馈、Paper Handoff、AI 使用记录和多人共同维护规则变成可验证的仓库契约。

**Architecture:** GitHub 仓库继续作为唯一正式源。根 `SKILL.md` 负责角色与任务路由，`skills/cumcm-rigorous-workflow/` 保存 Shared Core、三个 Role Profile、轻量 manifest 与 runtime references；现有 `04_验收冻结/`、`05_论文与图表/`、`06_协作与交接/`、`07_AI协作/` 继续作为 canonical workflow。Runtime Lite 由构建脚本从 canonical 文件组装，避免维护第二套长期漂移的规则副本。

**Tech Stack:** Markdown, YAML, JSON, CSV, Python 3 standard library, Git/GitHub.

**Spec:** `docs/superpowers/specs/2026-09-07-v2.1-orchestrator-paper-gates-design.md` + `docs/superpowers/specs/2026-09-07-v2.1-shared-three-gpt-skill-amendment.md`

## Global Constraints

- 2026 CUMCM 默认主选 C 题；A-Track 仅保留可迁移经验。
- 华数杯 C 题成绩为三等奖，评委反馈作为正式 Failure Evidence，不表述为一等奖唯一标准。
- 三套 GPT 共用同一个 Shared Core；角色值只允许 `FYQ_TECHNICAL_ORCHESTRATOR`、`XXT_MATHEMATICAL`、`CYQ_PAPER`。
- 无角色绑定时不得猜测角色，只允许询问一次或以 role-neutral read-only 模式工作。
- 官方材料、当前 `project_state.yaml`、Frozen Source of Truth、canonical workflow 的事实优先级不得被 Profile 覆盖。
- `FROZEN` 结果只有 P0 问题才能重新打开，必须建立新版本并重跑依赖 Gate。
- Runtime Lite 不包含 PDF、PNG、JPG、JPEG 等大型论文语料；全文继续从 Project Files / Full Archive / 外部学术检索获取。
- `.cumcm-agent.local.yaml` 仅保存个人本地角色绑定，必须被 Git 忽略。
- 三人均可贡献 Skill，正式规则只认合并后的 GitHub main；不得维护长期个人最终 ZIP 分叉。
- 修改 Shared Core 至少需要另一角色 Review；跨角色 Handoff 由输出方与消费方共同 Review。
- 实施遵循 TDD：先建立静态契约测试并看到失败，再逐项实现直到通过。

- [ ] **Step 1: 写失败测试**

`tests/test_runtime_skill_contract.py` 使用标准库 `unittest`，至少包含以下断言：

```python
from pathlib import Path
import unittest

ROOT = Path(__file__).resolve().parents[1]
SKILL_DIR = ROOT / "skills" / "cumcm-rigorous-workflow"

class RuntimeSkillContractTests(unittest.TestCase):
    def test_three_role_profiles_exist(self):
        expected = {
            "FYQ_TECHNICAL_ORCHESTRATOR.md",
            "XXT_MATHEMATICAL.md",
            "CYQ_PAPER.md",
        }
        actual = {p.name for p in (SKILL_DIR / "profiles").glob("*.md")}
        self.assertEqual(actual, expected)

    def test_dispatcher_mentions_all_roles_and_active_role(self):
        text = (ROOT / "SKILL.md").read_text(encoding="utf-8")
        for token in (
            "ACTIVE_ROLE",
            "FYQ_TECHNICAL_ORCHESTRATOR",
            "XXT_MATHEMATICAL",
            "CYQ_PAPER",
        ):
            self.assertIn(token, text)

    def test_runtime_skill_contains_no_large_corpus_binary(self):
        forbidden = {".pdf", ".png", ".jpg", ".jpeg"}
        bad = [p for p in SKILL_DIR.rglob("*") if p.is_file() and p.suffix.lower() in forbidden]
        self.assertEqual(bad, [])

    def test_local_role_binding_is_ignored(self):
        text = (ROOT / ".gitignore").read_text(encoding="utf-8")
        self.assertIn(".cumcm-agent.local.yaml", text)

    def test_project_state_has_three_agent_bindings(self):
        text = (ROOT / "templates" / "project_state模板.yaml").read_text(encoding="utf-8")
        for token in ("agent_bindings:", "FYQ_TECHNICAL_ORCHESTRATOR", "XXT_MATHEMATICAL", "CYQ_PAPER"):
            self.assertIn(token, text)

    def test_paper_profile_blocks_unsupported_final_prose(self):
        text = (SKILL_DIR / "profiles" / "CYQ_PAPER.md").read_text(encoding="utf-8")
        self.assertIn("INCOMPLETE", text)
        self.assertIn("缺口清单", text)
        self.assertIn("可直接定稿", text)

if __name__ == "__main__":
    unittest.main()
```

- [ ] **Step 1: 在模型 Gate 增加结论等级**

正式定义：

```text
FEASIBLE      = hard constraints 通过
COMPETITIVE   = 同口径稳定优于合理 baseline
NEAR-OPTIMAL  = 额外存在 gap / bound / exact anchor / 强最优性证据
```

并明确 GroupedMean 只能做 baseline、区间必须 downstream replay、顺序启发式必须 permutation stress、可解子问题需 exact anchor、结构假设需 counterfactual、储能需容量×功率 surface、经验阈值需扫描、迭代终止含服务质量、infeasible 需边界诊断。

- [ ] **Step 2: 写 Robustness Plan**

模板分四栏：Numerical Stability、Parameter Sensitivity、Decision Robustness、Statistical Uncertainty；禁止统一机械 ±10%。

- [ ] **Step 3: 升级 Figure Registry**

CSV 字段：`figure_id,question,type,purpose,claim,data_owner,freeze_version,source_file,script,reviewer,status,layout_risk`，type 只允许 result/mechanism/diagnostic/robustness。
