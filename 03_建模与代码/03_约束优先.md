# 约束优先

优化题统一遵循：

```text
可行性 > 口径正确 > 可复现 > 指标优化
```

## 每次正式结果先出 constraint report

建议字段：

| 检查项 | 最大违反量 | 违反次数 | PASS/FAIL |
|---|---:|---:|---|
| 容量 |  |  |  |
| 时限 |  |  |  |
| 功率平衡 |  |  |  |
| SOC |  |  |  |
| 购售电边界 |  |  |  |
| 网络时延 |  |  |  |
| 终端约束 |  |  |  |

只有全部 PASS 后，才报告：
- cost；
- carbon；
- latency；
- renewable utilization；
- peak；
- waiting time 等目标或评价指标。

**一个不可行的“低成本方案”没有论文价值。**
