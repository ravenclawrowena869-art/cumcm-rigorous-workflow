# 一页总控流程 v2.0

## 核心结构：三轨并行

```text
                         ┌─────────────────────┐
                         │  题目 / 官方规则 / 数据  │
                         └──────────┬──────────┘
                                    ↓
                         共同读题 + 路线评审
                                    ↓
          ┌─────────────────────────┼─────────────────────────┐
          ↓                         ↓                         ↓
   Paper Pipeline             Technical Pipeline        Mathematical Pipeline
      CYQ 主责                  FYQ 主责                  XXT 主责
          ↓                         ↓                         ↓
文献/骨架/问题分析       数据/代码/AI/接口/版本       数学抽象/目标/约束/审核
          ↓                         ↓                         ↓
          └─────────────── 结构化交付物交换 ───────────────┘
                                    ↓
                     单问 FROZEN + 三重验收
                                    ↓
                      Paper Metrics / Figure Data
                                    ↓
                         正文 / 图表 / 摘要
                                    ↓
                           PAPER_LOCKED
                                    ↓
                         FINAL SUBMISSION
```

---

# 五级 Gate

## G0 — Problem Contract
必须确认：
- 官方要求
- 数据字典
- 时域 / 单位
- 四问真实依赖
- 提交规则
- AI 使用规则
- 第一版模型路线
- 跨问接口草案

## G1 — Runnable Mainline
每问至少：
- 一个 baseline
- 一条可运行主线
- 一个稳定输出 schema
- 基本 hard constraint 检查

## G2 — Mathematical & Technical Validation
必须：
- hard violation = 0
- 数学审核通过
- 技术审核通过
- 指标口径固定
- 接口稳定

## G3 — Freeze
必须：
- clean replay
- manifest
- source of truth
- paper metrics
- figure data
- 三重验收完成

## G4 — Submission
必须：
- 摘要/正文数字一致
- 图表来源一致
- 页数与格式合规
- AI 说明合规
- PDF/附件最终人工检查

# 两条禁令

## No Pure Waiting
任何成员的主任务被依赖阻塞超过约 15–30 分钟，应切换 Secondary Queue。

## No Role Swap for Tool Failure
Codex / Claude Code / 网络 / 单一工具故障，优先切换工具或设备。
不得因为 coding agent 故障就重排 FYQ / XXT 的长期角色。
