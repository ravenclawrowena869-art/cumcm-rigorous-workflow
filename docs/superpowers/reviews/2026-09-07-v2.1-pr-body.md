# PR Body Draft

## Why

将仓库升级为 FYQ、XXT、CYQ 三套 GPT 共用的 Shared Runtime Skill，并把 2026 华数杯 C 题三等奖评委反馈沉淀为正赛可执行的模型 evidence、稳健性、论文求解过程、图表与 AI 使用 Gate。

## Changed Rules

- 新增 Shared Core 和三个 Role Profile；
- 新增 ACTIVE_ROLE 路由与本地角色绑定；
- FYQ GPT 负责 Technical + Orchestrator，XXT GPT 负责 Mathematical Review，CYQ GPT 负责 Paper；
- 新增 FEASIBLE / COMPETITIVE / NEAR-OPTIMAL；
- 强化时序 challenger、downstream interval protection、permutation stress、exact anchor、counterfactual、参数扫描和不可行边界诊断；
- Paper Handoff 增加本问中心逻辑、真实伪代码包、自然语言初稿和论文禁区；
- AI 使用采用聊天记录 → 知识库 → 团队框架 → 人工重写，并维护完整 Ledger；
- Runtime Skill 与大型论文 corpus 分离。

## Affected Profiles

- FYQ_TECHNICAL_ORCHESTRATOR
- XXT_MATHEMATICAL
- CYQ_PAPER

## Behavior Change

同一 Skill 根据 ACTIVE_ROLE 改变默认工作重点与输出契约；三套 GPT 共享 project_state、Handoff、Frozen Source 和 Git，不再依靠跨聊天记忆同步正式状态。

## Backward Compatibility

保留 v2.0 的三轨并行、动态 Owner、Interface First + Mock、Blocked Rule、Freeze、clean replay、Figure evidence chain 和 Final Submission Gate。专项冻结任务仍遵守最小修改原则。

## Evaluator Feedback Incorporated

华数杯三等奖评委指出的时序适配、预测区间保护效果、任务顺序敏感性、MILP/exact anchor、结构假设 counterfactual、储能参数扫描、经验阈值扫描、多指标终止、场景收敛差异、不可行边界、求解伪代码和版面问题均已转为通用 Gate。

具体 20% cap、RegionA 与三张 Q4 图保存在 `09_本次比赛复盘/04_Q4赛前闭环演练Authority.md`，没有硬编码进 Shared Core。

## Runtime Lite / Corpus Separation

`tools/build_runtime_skill.py` 根据 manifest 组装 Runtime Lite。`.pdf/.png/.jpg/.jpeg` 禁止进入 Runtime Skill。大型优秀论文继续保存在 Project Files / Full Archive。

## Evidence / Source

- 两份 v2.1 design spec；
- 华数杯 C 题三等奖评委反馈；
- 现有模型 Evidence Gate、Paper Pipeline、Figure Pipeline、Final Submission Gate；
- 用户确认的三 GPT 共用与共同维护方式；
- CYQ 提供的 Q4 赛前闭环主控指令。

## Migration Notes

- FYQ: FYQ_TECHNICAL_ORCHESTRATOR
- XXT: XXT_MATHEMATICAL
- CYQ: CYQ_PAPER

平台允许时复制 `templates/cumcm-agent.local.example.yaml` 为 `.cumcm-agent.local.yaml`；否则在各自 Project / Custom Instructions 保留一条简短 ACTIVE_ROLE 绑定。
