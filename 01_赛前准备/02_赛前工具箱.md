# 赛前工具箱

建议提前准备，而不是比赛现场搭环境。

## 必备

- Python 环境；
- `requirements.txt` / `environment.yml`；
- Git 仓库；
- Excel / CSV 读取脚本；
- 字体与中文绘图测试；
- PDF / Word / LaTeX 模板；
- 最终压缩脚本；
- hash / manifest 脚本；
- 单元测试模板；
- 运行时间记录；
- AI 使用记录模板。

## 预先测试

1. 中文 Matplotlib 坐标轴是否正常；
2. Excel 日期、空值、百分数、单位是否读取正确；
3. Windows / macOS 路径是否兼容；
4. ZIP 解压后能否从新目录运行；
5. Overleaf 是否可能 timeout；
6. 图转 PDF/PNG 后是否模糊；
7. 附录代码如何拆分；
8. 最终 PDF 合并方案。

## 赛前准备的真正目标

不是提前猜题，而是把“低价值工程问题”移出比赛时间。
