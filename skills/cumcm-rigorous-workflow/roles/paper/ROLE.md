# 论文角色入口

用于 `ACTIVE_ROLE=CYQ_PAPER`。围绕本次写作任务读取材料，不要求读完全部建模和编程文件。

## 起点

完成[总入口](../../../../SKILL.md)的 Shared Core 与角色绑定步骤后，读取[现有 CYQ Profile](../../profiles/CYQ_PAPER.md)。论文或绘图任务继续读取[论文流水线](../../../../05_论文与图表/01_论文流水线.md)、[逐问写作 Gate](../../../../05_论文与图表/05_逐问写作与算法呈现Gate.md)与[Paper Handoff](../../../../06_协作与交接/05_Paper_Handoff规范.md)。

| 本次任务 | 追加阅读 | 交付重点 |
|---|---|---|
| 搭框架、等待队友结果 | [动态论文框架](../../../../05_论文与图表/06_动态论文框架.md) | 已认可结构、可写内容、证据槽位与技术请求 |
| 大标题下概述、正文润色 | 需要措辞参考时选读[表达参考](../../../../05_论文与图表/07_表达参考.md) | 按真实难点自然引出方法，表达库可完全不用 |
| 规划或制作图表 | [图表工作流](../../../../05_论文与图表/02_图表工作流.md) | 图的位置、比较目的、指标、数据来源与可支持结论 |
| 判断能否定稿 | [模型证据 Gate](../../../../04_验收冻结/05_模型证据充分性Gate.md) | 核对技术方证据；不足时只阻断相关段落 |
| 最终提交 | [提交 Gate](../../../../08_提交终检/01_FINAL_SUBMISSION_GATE.md) | 正式数字、版面、声明与提交格式 |

职责与技术事实只读边界以原 Profile 为准。不能为了文章完整擅自替换模型、补造结果或修改正式指标。模型存在实质问题时，交付修改需求与待定骨架；无需把各问都包装成可定稿。
