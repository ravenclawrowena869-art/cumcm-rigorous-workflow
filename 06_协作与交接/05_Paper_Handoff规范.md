# Paper Handoff

Paper Lead 不负责进入代码包寻找论文事实。

每个模块进入 FROZEN 后，Owner 必须提供一份 Paper Handoff。

## 必填字段

```text
模块：
版本：
Owner：
数学审核：
技术审核：

【方法】
最终采用什么？

【为什么】
为什么选它而不是备选？

【核心数学】
最重要的目标 / 约束 / 公式是什么？

【核心结果】
正式指标、单位、场景。

【结果解释】
结果说明什么？

【正式来源】
source file / row / column / freeze version

【图表】
建议哪些图？图的数据在哪？

【论文禁区】
哪些口径不能误写？
哪些旧结果已经废弃？
```

## 目标

CYQ拿到 Handoff 后，应当能够直接完成正文，
而不需要重新阅读整套代码和聊天记录。
