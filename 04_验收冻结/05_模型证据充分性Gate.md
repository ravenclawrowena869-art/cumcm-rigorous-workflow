# 模型证据充分性 Gate v2.2

模型“能够运行”不等于“可以写进论文”。本 Gate 在模型冻结和 Paper Handoff 之前执行，用于检查论文中的主要结论是否有足够证据支撑。

从 v2.2 起，本 Gate 与 `04_验收冻结/06_条件触发Gate与证据协议.md` 联动：先做通用证据检查，再根据模型结构生成 Triggered Gate List。任何被触发的结构 Gate 未关闭时，不得进入 Freeze。

## 一、先建立结论—证据表

每个拟写入正文的核心结论必须记录：

| 结论 | 所需证据 | 实际文件/字段 | 状态 |
|---|---|---|---|
| 当前模型优于备选 | 同口径基线或候选模型比较 |  |  |
| 算法接近最优 | 精确解、小规模真值或可核验下界 |  |  |
| 结果稳定 | 多种子、重排、重采样或重复划分 |  |  |
| 参数合理 | 参数来源或“改参数→重新求解”敏感性 |  |  |
| 模型鲁棒 | 噪声、极端情景或分布漂移实验 |  |  |
| 不可行有现实原因 | 最小可达边界、约束松弛量或 IIS |  |  |

没有证据的结论只能标记为“待验证”，不得换一种更肯定的措辞写进论文。

## 二、按模型类型检查

### 预测模型

- 至少有朴素或统计基线，并使用时间顺序正确的验证方式；
- 检查极端误差、系统性偏差和结构突变/分布漂移；
- 给出区间时，必须检查覆盖率、区间宽度，以及区间对后续容量、调度或风险决策的保护效果；
- 若预测结果进入下一问，必须检验误差传播或上下界情景。

### 启发式、贪心与随机优化

- 说明任务处理顺序、并列规则、随机种子和停止条件；
- 做输入重排、多随机种子或多起点实验，报告均值、标准差和极差；
- 在可计算的小规模或代表性子问题上，用 MILP、DP、枚举、下界或松弛解建立性能锚点；
- 不能仅比较三套人工预设策略后就声称“最优”。

### LP、MILP 与其他约束优化

- 复算目标值、变量边界、等式平衡和全部硬约束；
- 报告求解状态、运行时间、最优间隙（适用时）和最大违反量；
- 对分区独立、无交互、确定性输入等结构假设，建立可实现的对照或理想上界；
- 对容量、功率、权重、预算、阈值等关键参数进行“修改参数并重新求解”的扫描。

### 交替迭代与多目标模型

- 对经验调整比例、步长、惩罚权重和终止阈值进行敏感性分析；
- 每轮同时记录目标、可行性、服务质量或其他题目要求的指标；
- 区分“收敛”“排程不再变化”“达到迭代上限”和“因不可行停止”；
- 若声称多目标权衡，至少给出极端点、规范化依据、Pareto/ε-约束结果或明确的主目标—约束结构；
- 不能把只在求解后统计的指标写成已被模型优化的目标。

## 三、不可行性诊断

出现不可行时，不得只写“约束较严格”。至少完成一种诊断：

- 求最小可达目标并与约束上限比较；
- 引入带惩罚的松弛变量，量化最小放松量；
- 提取 IIS 或绑定约束；
- 分区域、分时段、分类别定位冲突来源。

正文解释必须把数学边界翻译成题目中的物理或业务机制。

## 四、结构 Gate 触发检查

在给出本 Gate 最终结论前，必须回答以下触发问题：

- 是否存在关键简化假设？→ CG1
- 是否存在逐步贪心、局部搜索、随机性或并列规则？→ CG2
- 是否使用非精确优化却需要评价方案质量？→ CG3
- 是否有关键约束接近边界或结果将进入下游继续调整？→ CG4
- 是否存在 A→B→A 的反馈迭代？→ CG5
- 是否把 dual、marginal value、score 等派生量作为下游决策信号？→ CG6
- 是否出现“迭代/收敛/稳定”表述？→ CG7
- 是否存在终端状态、峰值、切换点或不可行边界？→ CG8
- 是否用多个方案比较支持“更优” Claim？→ CG9
- 是否出现异常漂亮、负值、接近零或数量级反常结果？→ CG10

详细标准见 `04_验收冻结/06_条件触发Gate与证据协议.md`。

## 五、Gate 结论

只允许以下状态：

- `EVIDENCE PASS`：主要结论均有可追溯证据，Triggered Gate 已全部关闭；
- `PASS WITH LIMITATION`：主线可用，但论文必须主动限定结论边界，相关 Gate 已记录 limitation/waiver；
- `FAIL / ADD EXPERIMENT`：缺少关键基线、敏感性、稳定性、结构 Gate 或不可行诊断，不得进入 Paper Handoff。
