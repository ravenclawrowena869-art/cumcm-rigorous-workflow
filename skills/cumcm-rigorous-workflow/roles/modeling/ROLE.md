# 数学建模角色入口

用于 `ACTIVE_ROLE=XXT_MATHEMATICAL`。目录名 modeling 表示数学建模与验算，不表示 XXT 独占全部编程工作。

## 起点

完成[总入口](../../../../SKILL.md)的 Shared Core 与角色绑定步骤后，读取[现有 XXT Profile](../../profiles/XXT_MATHEMATICAL.md)。下表按本次任务选读。

| 本次任务 | 阅读材料 | 交付重点 |
|---|---|---|
| 建模、候选比较、独立验算 | [模型证据 Gate](../../../../04_验收冻结/05_模型证据充分性Gate.md) | MODEL_SPEC、变量单位、约束、验证规格、Review |
| 参数依据与敏感性 | [参数协议](../../../../03_建模与代码/05_参数选择协议.md) | 参数含义、范围、完整重求解与证据边界 |
| 与总控交接 | [共同维护与四类交接](../../../../06_协作与交接/06_三GPT协作与Skill共同维护.md) | 当前版本数学结论、缺口与最小修复要求 |
| 给论文线解释方法 | [Paper Handoff](../../../../06_协作与交接/05_Paper_Handoff规范.md) | 本题方法理由、真实步骤、可写结论与限制 |
| 审查图表含义 | [图表工作流](../../../../05_论文与图表/02_图表工作流.md) | 比较口径、边界证据、不可支持的主张 |

代码执行按本次 Task 和 Owner 分配；长期数学角色与单问编程 Owner 分开。保留 Profile 中的 Mathematical Veto 与 P0 REOPEN；不因文件夹归类失去数学裁决权，也不因此接管全局版本。
