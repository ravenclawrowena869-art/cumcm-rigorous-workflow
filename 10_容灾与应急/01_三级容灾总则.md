# 三级容灾总则

容灾优先顺序：

```text
工具层
  ↓
设备层
  ↓
人员层
```

只在低层无法解决时升级。

## Level 1 — Tool Failover
例如：
- Coding Agent 不可用
- 单个账号异常
- 单个服务故障

处理：
- 切 Secondary Agent
- 角色不变

## Level 2 — Device Failover
例如：
- 电脑故障
- 本地环境损坏

处理：
- 另一台设备 clone repo
- 恢复环境
- 角色不变

## Level 3 — Person Failover
例如：
- 成员生病
- 长时间离线
- 无法继续比赛

处理：
- Deputy 只接关键职责
- 不做完整角色互换
- 必要时主动降级目标

核心原则：

> 故障范围有多大，组织调整就做到多大。
