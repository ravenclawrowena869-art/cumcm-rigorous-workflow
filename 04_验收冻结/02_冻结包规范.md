# 冻结包规范

建议每问最终产生一个独立 frozen package。

## 最低内容

```text
Qx_vX.Y_FINAL_FROZEN/
├─ src/
├─ tests/
├─ data_or_input_manifest/
├─ output/
├─ docs/
│  ├─ MODEL.md
│  ├─ METRICS.md
│  ├─ VALIDATION.md
│  └─ PAPER_SOURCE.md
├─ requirements.txt
├─ RUN.md
└─ FREEZE_MANIFEST.csv
```

## `PAPER_SOURCE.md`

必须明确告诉论文组：

```text
表 6.1:
来源文件：output/metrics.csv
字段：cost, carbon, latency
行：scenario=BASE

图 6.2:
来源文件：output/migration_detail.csv
绘图脚本：figures/make_fig6_2.py
```

这是避免“数字对，但来源错”的关键文件。
