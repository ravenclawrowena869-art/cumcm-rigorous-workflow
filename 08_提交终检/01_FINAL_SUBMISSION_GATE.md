# FINAL SUBMISSION GATE v2.1

最终 4–6 小时原则上不再改核心模型。任何未通过项都必须记录 Owner、处理方式和是否阻断提交。

## A. 题意

- [ ] 每问都有明确回答；
- [ ] 没遗漏题目要求的图、表、指标或附件；
- [ ] 单位、时域、粒度和终端条件正确；
- [ ] 正文没有把题目未要求或模型未处理的内容写成已解决。

## B. 模型与结果

- [ ] frozen 版本已记录；
- [ ] 每问通过模型证据充分性 Gate；
- [ ] hard constraint 全 PASS；
- [ ] 目标值与 2–3 个核心指标已独立复算；
- [ ] 基线、候选模型或精确/下界锚点充足；
- [ ] 随机/顺序敏感算法完成多种子、重排或多起点检查；
- [ ] 关键参数完成“改参数→重新求解”的敏感性分析；
- [ ] 不可行情景给出最小边界、松弛量、IIS 或绑定约束解释；
- [ ] 摘要、正文、图表和场景名称一致。

## C. 每问写作与算法呈现

- [ ] 每问大标题后有输入—困难—方法—评价—结果概述；
- [ ] 每个模型在公式前说明为何适合本题及相对备选的优势；
- [ ] 每问有题目特定的伪代码、算法流程或计算流程；
- [ ] 伪代码包含真实输入、关键变量、约束检查、停止条件和失败分支；
- [ ] 求解流程与公式、代码、参数和输出一致；
- [ ] 没有用“预处理—建模—求解—分析”类通用流程代替真实算法；
- [ ] 声称稳定、鲁棒、优越或不敏感的地方均有实验；
- [ ] 多目标模型没有把事后统计指标误写成已优化目标；
- [ ] 模型优点在相应章节有证据地呈现，不只集中在最后一节。
