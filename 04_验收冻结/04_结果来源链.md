# 结果来源链

所有正式结论都遵循：

```text
官方附件
  ↓
冻结代码
  ↓
冻结输出 CSV/JSON
  ↓
paper metrics
  ↓
图 / 表
  ↓
正文句子 / 摘要
```

## 禁止

```text
聊天里的数字 → 论文
截图里的数字 → 论文
旧图标签 → 新表格
人工重新算但不记录来源 → 论文
```

## 最终建议建立 `paper_number_registry.csv`

字段：
- section
- claim_id
- metric_name
- value
- unit
- source_file
- source_row
- source_column
- freeze_version
- checked_by

这样改论文时不再靠记忆。
