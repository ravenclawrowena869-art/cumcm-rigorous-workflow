# 读题协议

三个人先独立读题，再统一。

## 每问必须回答的 8 个问题

1. 输入是什么？
2. 决策变量是什么？
3. 输出是什么？
4. 评价指标是什么？
5. 硬约束是什么？
6. 这一问依赖上一问的“结果”还是只依赖“方法”？
7. 哪些附件字段必须使用？
8. 哪些地方最容易口径出错？

## 建立三张表

### A. 数据字典
字段 / 单位 / 缺失 / 取值范围 / 属于输入还是基准结果。

### B. 四问依赖图
只画真实传递关系，避免“为了好看”制造依赖。

### C. 口径风险表
记录：
- 时域；
- 单位；
- 碳排公式；
- 功率映射；
- 边界；
- 终端条件；
- 是否允许迁移 / 延迟 / 抢占。

## 规则

任何一个关键口径如果三个人理解不一致，先解决，不要各写各的。
