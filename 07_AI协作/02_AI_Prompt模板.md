# AI Prompt 模板 v2.1

## 通用任务模板

```text
你正在处理数学建模比赛项目。

【任务背景】
...

【必须读取】
- README.md
- project_state.yaml（若存在）
- 与本轮任务对应的 workflow / Gate
- ...

【本轮唯一目标】
...

【允许修改】
- ...

【禁止修改】
- 不改变模型口径
- 不改变正式指标定义
- 不修改无关文件
- 不覆盖 frozen 输出
- 不凭空生成结果
- 不用通用语言掩盖证据缺失

【验收标准】
1. ...
2. ...
3. tests 全部通过
4. hard violation = 0
5. 给出修改文件清单

【交付】
- 修改后的文件
- 测试结果
- 核心指标
- 风险
- 回滚方式
- 未完成事项

先分析原因，再进行最小修改。
```

## 论文写作 / 审稿追加段

```text
本轮涉及数学建模论文，必须读取：
- 04_验收冻结/05_模型证据充分性Gate.md
- 05_论文与图表/01_论文流水线.md
- 05_论文与图表/05_逐问写作与算法呈现Gate.md
- 06_协作与交接/05_Paper_Handoff规范.md
- 本问 Paper Handoff

写作前先列：
1. 已有冻结证据；
2. 缺失实验、数字或算法步骤；
3. 可以直接定稿的部分；
4. 只能保留占位符的部分。

每问大标题后写本问概述。算法引出必须结合本题数据、变量、约束和规模，不能写通用教材介绍。每问给出与正式代码一致的伪代码、流程图或计算流程，包含输入、初始化、循环/选择、硬约束、停止条件和失败分支。

若 Paper Handoff 或验证证据不足，停止生成“可直接定稿”的表述，先返回缺口清单。不得编造实验、数字或模型优势。
```
